Project Overview

The Python Programming Glossary is a menu-driven command-line application developed using Python.

It allows users to search for programming-related terms, retrieve their definitions, add new words, update existing definitions, and view all available entries stored in a dictionary.

The application uses a Python dictionary as its data store, where each programming term is stored as a key and its corresponding definition is stored as a value.

The project was developed to improve my understanding of Python dictionaries, functions, loops, conditional statements, and basic data management operations.

Features

Word Lookup: Allows users to search for programming terms and retrieve their definitions.

Add New Words: Enables users to add new programming terms and their definitions.

Update Existing Words: Allows users to update the definition of an existing term.

View All Words: Displays all stored programming terms and their definitions in alphabetical order.

Input Validation: Prevents users from submitting empty words or definitions.

Invalid Input Handling: Displays an error message when users select an unavailable menu option.

Interactive Main Menu: Uses a continuous while loop to allow users to perform multiple operations without restarting the application.

Dictionary Storage: Uses Python dictionaries to organise and manage programming terms and definitions.

Technologies Used

Python 3 – Main programming language.

Python Dictionaries – Used to store programming terms and their definitions.

Built-in Python Functions – Used for searching, sorting, retrieving, and managing dictionary entries.

How It Works

The application uses a menu-driven interface with four options:

Search for a Word: The user enters a programming term, and the application searches the dictionary for its definition.

Add or Update a Word: The user enters a new term and its definition. If the term already exists, its definition is updated.

View All Words: Displays all available programming terms and definitions in alphabetical order.

Quit: Exits the application.
